这是给站点监控系统调用的大陆探测节点，运行在中国大陆地域。本页面只用于人工自检： 确认节点是否在线、部署在哪个地域，并手工发起一次探测查看延迟。

令牌就是部署时配置的 PROBE_TOKEN，只保存在当前浏览器本地（localStorage），不会上传到任何第三方。 填写并保存后会自动重新检测节点状态。

本服务仅执行只读探测：向目标地址发起一次 HTTP 请求并读取响应，不写入、不保存、不转发任何数据。 节点运行在中国大陆地域，因此这里测得的延迟与可达性反映的是中国境内网络的视角， 与境外监测点看到的结果可能存在差异。探测结果中的「请求成功 / 请求失败」只表示 HTTP 层是否跑通， 不代表站点本身的可用性结论。
